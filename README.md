# Alarm Notifications App

A modern, glassmorphic alarm notification UI app inspired by ColorOS 17, built for Expo Go.

## 📱 Quick Start with Expo Go (iPhone)

### 🚀 Option 1: Instant QR Code (Fastest - 2 min)
1. Download **Expo Go** on your iPhone (free from App Store)
2. Run: `npm install && npx expo start`
3. Scan the QR code with iPhone camera
4. Tap "Open in Expo Go"
5. **Done!** ✅

### 🔗 Option 2: GitHub + Shareable Link (10 min)
1. Push this repo to GitHub
2. Run `npx expo start`
3. Get an `exp://exp.host/@yourname/alarm-notifications-app` link
4. Share it with anyone - they can open in Expo Go!

**👉 [Full GitHub Setup Guide →](COPY_PASTE_INSTRUCTIONS.md)** (copy-paste ready!)

## Features
- ✨ Glassmorphic card design
- 🎯 Interactive snooze options (5m, 10m, 15m)
- 📱 Smooth animations and transitions
- 🎨 Customizable colors, icons, and labels
- ⏰ Multiple alarm management
